# Security and Correctness Findings

Register of findings from security reviews, with how each was proven, fixed and guarded. New reviews append rows; rows are never deleted. Phase 3 code-review findings CR-1 to CR-10 are in the [Phase 3 log](../phases/phase-03-auth.md#5-code-review-findings).

**Evidence levels:** *Reproduced*: a test or command showed the defect on the real code before the fix. *Statically confirmed*: shown by reading the code or the framework source, without a running reproduction. **Status:** *Fixed* (regression test in place), *Mitigated* (risk reduced; residual risk stated), *Accepted* (no change, with a reason).
